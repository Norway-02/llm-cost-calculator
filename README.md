# AI LLM Token & Cost Calculator

> Ultra-fast, trustworthy, privacy-first developer utility for calculating, comparing, and forecasting LLM API costs.

![Next.js](https://img.shields.io/badge/Next.js-16.3-black)
![TypeScript](https://img.shields.io/badge/TypeScript-5.0-blue)
![TailwindCSS](https://img.shields.io/badge/Tailwind-4.0-38bdf8)

## 🚀 Features

- **Instant Live Calculations**: Pure client-side deterministic engine calculating cost/request, daily, weekly, monthly, and annual billing.
- **100% Verified Pricing Data**: Schema-validated data layer for 14+ models across OpenAI, Anthropic, Google Gemini, DeepSeek, Meta, Mistral, and Cohere.
- **Freshness & Trust Warnings**: Visible indicators for verified, stale, or unverified pricing data with links to official provider docs.
- **Side-by-Side Comparison**: Compare 2 to 5 models simultaneously with automatic lowest-cost highlighting. Responsive desktop table & mobile stacked cards.
- **Client-Side Token Estimator**: Calculate character count, word count, and estimated tokens locally without transmitting text.
- **State & Shareability**: Bi-directional URL parameter state binding and Web Share API / clipboard integration.
- **Calculation History**: Safe local storage drawer to save, restore, and manage past calculations.
- **10 Functional SEO Routes**: Pre-configured routes for specialized search queries with internal linking.

## 🛠️ Getting Started

```bash
# Clone the repository
git clone https://github.com/example/llm-cost-calculator.git
cd llm-cost-calculator

# Install dependencies
npm install

# Run dev server
npm run dev

# Run Vitest test suite
npm test

# Run TypeScript typecheck
npm run typecheck

# Run ESLint
npm run lint

# Build for production
npm run build
```
